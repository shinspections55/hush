Install the App (PWA)

iPhone (Safari)

Important: Use Safari. Apple only allows installing web apps from Safari.

  1. Open the website in Safari.
  2. Tap the Share button (the square with an upward arrow) at the bottom of the screen.
  4. Scroll down and tap Add to Home Screen.
  6. (Optional) Edit the app name if you would like.
  7. Tap Add in the upper-right corner.
  8. The app icon will appear on your Home Screen just like any other app.
  9. Tap the icon anytime to launch the app in full-screen mode.

Android (Chrome, Edge, or Samsung Internet)

Option 1: Install Prompt (Recommended)

If your browser displays an Install App or Install prompt:

  1. Tap Install.
  2. Confirm by tapping Install again.
  3. The app will be added to your Home Screen and App Drawer.

Option 2: Add to Home Screen

If you do not see an install prompt:

  1. Open the website in your browser.
  2. Tap the three-dot menu in the upper-right corner.
  3. Tap Add to Home screen or Install app (wording varies by browser).
  4. Confirm by tapping Add or Install.
  5. The app will now appear on your Home Screen.

Tips

  • Make sure you are using a supported browser (Safari on iPhone, Chrome/Edge/Samsung Internet on Android).
  • An internet connection is usually required for the initial installation.
  • Once installed, the app launches like a native app with its own icon and full-screen experience.
  • If the website has been updated recently and you do not see an install option, refresh the page and try again.

Need Help?

If you do not see an Install or Add to Home Screen option:

  • Make sure you are using the supported browser.
  • Refresh the page and try again.
  • Visit the website over a secure HTTPS connection.
  • Ensure your device is running a current version of iOS or Android.

If you are still having trouble, please contact us and let us know:

  • Your device model
  • Your operating system version
  • The browser you are using
